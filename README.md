# Software Engineering Sandbox

This repository contains a collection of software engineering projects, exercises, and implementation challenges completed while studying full-stack web development. 

The projects in this repository span frontend development, backend APIs, databases, and application architecture. Together they demonstrate practical experience building and working with modern web technologies across the full stack.

---

## 🛠️ Technologies Covered

### **Frontend**
* **Framework:** React
* **Routing:** React Router
* **Architecture:** Component Architecture & State Management
* **Hooks:** `useState`, `useEffect`, `useRef`

### **Backend**
* **Environment & Framework:** Node.js, Express
* **Architecture:** REST APIs, Middleware, Routing Patterns

### **Databases**
* **NoSQL:** MongoDB, Mongoose
* **Relational:** PostgreSQL, SQL Querying, and Database Design

---

## 📂 Repository Contents
Projects range from focused implementation exercises to larger multi-feature applications. Key topics covered include:
* React state management and routing
* Express API development, middleware, and request handling
* MongoDB operations and schema design
* SQL querying, joins, and database modeling
* Node.js utilities and backend workflows

## 🎯 Purpose
This repository serves as a development sandbox and learning archive, showcasing hands-on implementation of full-stack software engineering concepts through practical projects and exercises.
